# Launcher icon assets

These raster assets are derived from the Adwaita icon library shipped on the
development system. They preserve the original Adwaita paths and are recolored
only to provide the light semantic foreground required by Maho Launcher's dark
glass surface.

Source icons: `view-app-grid-symbolic`, `applications-system-symbolic`,
`system-search-symbolic`, `go-next-symbolic`, `go-down-symbolic`, and
`go-up-symbolic`.

Adwaita icons are distributed by the GNOME project under the terms documented
with the installed icon package. Maho does not claim authorship of them.
